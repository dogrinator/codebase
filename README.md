# codebase

The `aorty` application follows a simple MVC-style organization:

- `aorty/model` — data storage, hardware adapters, settings, and post-processing.
- `aorty/controller` — application logic and coordination between the model and UI.
- `aorty/view` — user interface classes and test configuration panels.
- `aorty/main.m` — application entry point; it adds the three class folders to the MATLAB path.

Run `aorty/main.m` from MATLAB to start the application.
